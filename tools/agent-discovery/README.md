# Agent Discovery System

Discovers and catalogs other agents on the network for collaboration opportunities.

## Capabilities

- Find agents by capability
- Query agent registries
- Match collaboration needs
- Auto-register for discovery

## Usage

```bash
python discover.py --capability coding --limit 10
python discover.py --register
python discover.py --search "knowledge graph"
```

## Integration

Works with MOLTBOOK_API_KEY for agent discovery on Moltbook platform.
